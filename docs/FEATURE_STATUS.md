# Feature status

## Connected features
Dashboard; 12 selectable interface languages; profiles; 8 Class 8 rational-number lessons; 32 exercises; local progress; adaptive practice; offline deterministic tutor; consent-gated optional cloud text/photo; browser speech; fraction game; visual math; guardian summary; achievements; export/delete; offline library.

New routes: /universe (all eight lessons and local completion), /revision (lessons with incorrect attempts), /games (catalog), /games/fractions (existing progress-enabled game), /games/equations, /games/number-line, /games/find-mistake, /brain-training (small English practice previews).

## Explicitly planned
Science simulations, language games and the other catalog entries without launch links. Their source modules show a planned message. /science-lab is an unavailable screen. No full Class 9/10 curricula are included.

## Reusable modules
The requested folders include presentation components, flashcards, accessible ordering, game session types, scoring and proposed XP helpers. These are not all mounted. XP is not persisted. Server /games, /missions, /rewards and /revision expose public catalogs only. Learner data remains local.

## Translation coverage
Telugu and English are the original supported interface/content packs. Hindi includes a draft lesson translation. Tamil, Kannada, Malayalam, Marathi, Bengali, Gujarati, Punjabi, Odia and Urdu translate core interface labels, fall back to English lessons and may fall back to English secondary labels. All ten additions are translation previews. Urdu has RTL layout.
