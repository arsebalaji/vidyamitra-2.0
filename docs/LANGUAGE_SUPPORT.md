# Language support

12 selectable interface languages: Telugu, English, Hindi, Tamil, Kannada, Malayalam, Marathi, Bengali, Gujarati, Punjabi, Odia and Urdu. Urdu uses right-to-left layout. Selection persists on this device.

Telugu and English retain MVP status. Hindi includes draft translations for all 8 lessons and 32 questions. The other nine new languages have translated core interface labels and English lesson content; missing interface strings fall back to English. All ten additions are clearly labeled translation previews pending educator/native-speaker review. An on-screen notice explains this on every page. Cloud tutor requests use the selected interface language; offline responses use the available lesson language. Browser speech support depends on installed voices.

The dark visual refresh uses an original glowing AI companion, translucent panels, violet/cyan buttons and mobile navigation. Progress displays use actual local activity.
