# Learning rules

Lessons remain accessible without mandatory unlocks. The learning universe shows actual device-local completion. Smart revision recommends any lesson with a recorded incorrect attempt; when none exist it suggests the first three lessons. It is a transparent rule, not a prediction of mastery.

All ten new interface languages remain translation previews. Hindi lesson content is a draft. Other additions fall back to English lesson content.

Game and lesson progress belongs to the active local profile. Cloud sync is not implemented. XP helpers are reusable proposals and are not mounted or persisted. A learning goal is based on overall recorded activity, not a daily streak.
