# Five-minute hackathon walkthrough

1. Start FastAPI, build the frontend and run `npm run preview`. Open `http://127.0.0.1:4173/welcome`.
2. Choose Telugu. Create a nickname-only learner. Explain that the initial “మిత్ర” profile is fictional and progress begins at zero.
3. Open Rational Numbers, then Addition & subtraction. Read all three steps and complete the lesson. Reload midway once to demonstrate resume.
4. Try practice. Use a hint and answer `1/2` to a question requiring a different fraction. Show worked feedback; repeat mistakes to show an easier level. Correct answers with equivalent fractions are accepted. Progress is saved automatically.
5. Ask Mitra using offline mode and the selected lesson. Clearly identify this as a deterministic lesson guide. Change between simple, step-by-step, examples and hint modes.
6. Use Math lab to move the numerator/denominator sliders, including a negative numerator. Play a round of Fraction detective. Show progress and the local guardian overview.
7. In Offline library, save the chapter. Wait for the app-cache ready message. Disable network and reload the same origin. Reopen lessons and practice. Reconnect: local progress stays local, with no automatic upload.
8. Switch profiles and show separate progress. Export one learner's JSON from Settings. Deletion affects the selected learner only.
9. If a Gemini key was configured beforehand, optionally demonstrate explicit online consent or a printed question photo without personal data. Otherwise show that the optional provider is honestly unavailable; do not present a mocked response as AI.

Talk track: “We completed one officially referenced chapter rather than claiming an entire curriculum. Core learning works without accounts, API keys or continuous internet. More languages stay disabled until reviewed.”
