# Adventure visual refresh

The new bright theme replaces the previously active dark orbit theme at the entry point. The old stylesheet remains for reference but is no longer imported. AdventureHero and LearningWorldCard are mounted in the dashboard. LearningUniverse, GameArena, BrainTraining and SmartRevision have live routes. Existing lessons, quiz, tutor and data storage remain intact.

The new supplied structure has 335 concrete file/directory entries; its ellipsis for other verified languages is not a filename. Prior compatibility modules are preserved. Named future-game modules intentionally show PlannedFeature instead of pretending to be completed games. Reusable UI components are not all mounted yet.

The student-team.png illustration was created with the built-in image-generation tool. Prompt: three cheerful Indian teenage students learning together with a tablet and mathematics book in a bright library, a yellow star mascot with blue headphones, royal blue, teal, purple and yellow accents, polished 3D cartoon illustration, no text, no logos, no UI. The image is decorative; all actual interface text is HTML and translatable.
