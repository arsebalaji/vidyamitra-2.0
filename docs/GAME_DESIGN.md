# Game design and current status

Fraction Quest is the existing multilingual fraction game and records attempts per learner. Equation Battle, Number Line Race, Find the Mistake and Memory Match expose existing small practice activities as English previews. Their names describe future game directions; they are simple exercises, not full simulations, and do not currently contribute to mastery.

All remaining registry entries are explicitly planned and have no launch link. Their named modules show an unavailable message if mounted. Science and language curricula are not shipped. No points, streaks or leaderboard numbers are fabricated.

The game catalog comes from shared/curriculum/telangana/class-8/mathematics/te/games.json. Frontend GameRegistry.ts matches this catalog. Server endpoints expose public catalogs, never learner progress.
